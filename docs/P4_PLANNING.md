# P4：预算约束下的有限候选建议

入口为 **Esc → 方案建议…**。本阶段为仓颉实现的确定性候选搜索，复用 P3 火势模型、后台配对计算和项目约束；不依赖在线模型。CangjieMagic 交互仍在 P5 实现。

## 完成一次建议流程

1. 打开 `examples/connector-camp.firebreak`，或使用已有标注场地。先标定宽度、预算、保护目标和禁区；可保留手工设计的已有处理。
2. Esc 打开菜单，点击“方案建议…”，再点击“生成建议”。搜索在后台执行，可以取消。
3. 用上/下一候选查看完整列表。侧栏给出类型、训练收益/元、留出目标接触和新增成本；底部显示留出剩余林地、总费用及是否推荐。
4. “地图预览”仅用金色边框显示新增处理格，不改变场地、预算、历史或传播燃料。“查看留出情景对照”复用 P3 双栏纹理回放，明确标注候选尚未应用；该对照的左栏仍是原始场地，P4 评分则相对于当前已有处理方案。
5. 确认后点击“手动应用”。必须先显示预览；一次应用对应一个撤销事务，之后可以返回编辑并修改。应用、撤销或其它输入修改使旧搜索与对照失效。
6. “导出全部候选指标”生成独立目录，保留当前冻结项目、全部可行候选、逐样本结果、参数及双语说明。导出不自动应用候选。

没有候选通过训练/复核时仍保留全部可行候选供检查，不伪造自动推荐。用户可以明确手动应用未自动推荐项；界面保留其复核状态。

## 候选生成与约束

固定 24×20 网格，最多 14 个去重后可行候选，不自动组合：

- 道路邻接：沿行/列收集邻接道路的可燃格，最多 8 个候选。
- 目标周边：距保护格四邻接曼哈顿距离不超过 1 或 2 的可燃邻域，最多 2 个候选，排除目标本身。
- 关键连接格：逐格移除当前燃料图中的一个格，检测连通片数是否增加，按最大连通片下降量选前 4 个。它是割点启发式，不是全局最小割或最优防火线。

道路/目标候选使用隔离带类型，关键格使用清理类型；当前模型中两类处理都移除对应燃料，区别主要为用户设置的成本。不会改写原有处理格或其类型。每个候选重新使用 Project.validate 校验地类、目标、禁区、标定与总预算。触及硬约束或超预算的整笔候选拒绝，不静默删格拼成另一个方案。

“无可行候选”只针对这个有限几何族，不表示全地图不存在其它可行方案。未标定或没有可燃起火位置时返回明确错误。

## 训练、排序与留出复核

每个候选都相对**当前处理方案**比较。训练集沿用 P3 的 8 组固定起火/seed；留出集为 8 组林地索引中间分位起火点，seed 偏移 104729。所有候选共享同一组训练输入及同一组留出输入。留出随机键与训练不同；它们不是现实火灾的独立观测，仍有相同模型假设。

按加权均值计算：

`训练评分 = (481 × 避免的目标接触格 + 净剩余林地增量) / max(新增费用, 1 元)`

481 为明确的教学权重（480 格网格加 1），不是现场损失估值。新增费用为 0 时分母使用 1 元，避免除零；原有处理费用仍计入总预算。烧损、清理和剩余仍满足 P3 守恒定义，清理代价不能被忽略。

训练资格要求目标接触均值不增加、剩余林地均值不减少，且至少一项改善（浮点容差 1e-9）。候选按训练评分降序，同分先选新增成本低者，再按生成顺序。只在训练有资格的候选中选择。留出复核使用同样的改善条件，可以否决训练选中项，不能据此改选另一个赢家。这样避免把复核集继续当成调参集。

列表和 CSV 保留复核失败、无收益或训练不合格的可行候选。只是在候选族中按上述规则推荐，既不保证全局最优，也不声称真实安全概率。对已生成集合没有进行贪心组合；当前没有必要先引入复杂优化器。

## 数据、任务与文件

PlanSearchJob 冻结完整输入与 revision，生成和评估仅在仓颉后台运行，不调用 SDL。取消传递到当前 EvaluationJob，每个模型步检查。只发布完整搜索；新输入、再次生成或退出时取消旧任务。主线程绘制预览和处理应用。

候选仅保存处理掩码、逐样本指标和摘要，不为每个候选长期保留整份内嵌底图或完整回放。批量计算关闭历史保留；需要双栏回放时，再用已选候选和固定留出情景生成完整快照。对照及其导出参数具有 `candidatePreview=true`，不能混同于已应用方案。

导出写入同父目录临时目录，完成后通过不覆盖的 Windows 重命名发布；已有报告保留，失败保留临时目录位置。

| 文件 | 内容 |
|---|---|
| site.firebreak | 当前搜索冻结的完整场地和已有方案 |
| candidates.csv | 全部可行候选的 ID、类型、费用、评分、训练/复核状态、汇总指标和 treatment_mask |
| samples.csv | 所有候选及当前方案的逐情景结果；candidate_id=-1 为当前方案 |
| parameters.json | 规则版本、无风、revision、训练及留出情景、权重、评分常数和选择结果 |
| report.md | 中文或英文的排序方法、约束、完整候选表、限制及使用说明 |

将 candidates.csv 的 treatment_mask 赋给 site.firebreak 的 treatment 字段，再用参数中的两组情景计算，可以复现对应候选。P3 预览导出另包含 PNG、CSV 和候选项目快照。
