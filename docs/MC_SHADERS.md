# MC 简化光照实验 v0.4.5

2026-11-02。主机端继续使用仓颉与 SDL3，GPU 内核使用现有 HLSL / D3D11 Compute。P5 智能体仍暂缓。

## 使用与当前渲染方式

`./run.ps1` → Esc → 显示选项 → **光影 / Shader**。默认关闭，设置仅保存在本地 `settings.local.json`，不写入项目文件。英文界面提供同一按钮。CPU 或已知 GPU 故障时按钮禁用；切回 GPU 保留上次选择。

大森林诊断 `./forest-stress.ps1` 中按 **L** 临时切换，右侧显示实际后端。`GPU D3D11 + MC FX` 表示光照实际运行在 GPU；没有静默把 CPU 着色当作 GPU 成功。

目前是每个原生视口像素一条正交射线，经世界 AABB → 8³ 空区块跳过 → 体素 DDA → 纹理最近邻采样/树叶 alpha 裁切 → 表面着色 → GPU 内部复制到 SDL 纹理 → SDL 界面、选区与火焰精灵叠加。静止复用结果。相机/光影变化只更新常量；仿真变化更新压缩列状态，场地修改才更新体素与占据数据。常规帧没有像素读回。

它仍是体素射线管线。Minecraft 原版的区块三角网格、光照传播、实时运行参数和全部后处理并未被搬入项目。

## 本地原版着色器核对

来源为用户提供的 `E:/CangJie/minecraft/shaders`，GLSL `#version 150`。目录本身未提供可核对的游戏版本，因此不标注为某个最新版本。原文件不复制到 Git 仓库。

本次核对文件的相对路径与 SHA256 保存在 [来源指纹](../artifacts/shader-source-hashes.json)。

| 本地文件 | 原版作用 | 当前处理 |
|---|---|---|
| `include/light.glsl` | 两方向 Lambert 光照；`min(1, (light0 + light1) × 0.6 + 0.4)`；16×16 光照贴图采样 | 在 HLSL 中适配方向光公式；光照贴图改为本项目的局部代理 |
| `core/rendertype_solid.vsh`、`rendertype_cutout_mipped.vsh` | 地形顶点色乘光照贴图，计算模型视图距离 | 保留材质/状态数据，按命中体素计算着色，无 MC 顶点光照数据 |
| `core/rendertype_entity_solid.vsh` | 调用 `minecraft_mix_light` 再结合光照贴图 | 双方向光公式的使用参考；不声称原版地形顶点也直接调用它 |
| `core/rendertype_cutout_mipped.fsh` | 纹理 alpha < 0.5 时舍弃，随后乘颜色并加雾 | 沿用现有树叶 byte alpha ≥ 128 的可见条件 |
| `include/fog.glsl` | `smoothstep(start,end,distance)` × 雾色 alpha 后混合，保留表面 alpha | 适配同一混合公式，调整正交距离定义 |
| `program/`、`post/` | 多种后处理效果，与运行时配置组合 | 此次未接入模糊、泛光、屏幕扭曲等额外通道 |

## 适配参数与现有材质编排

开启后，以双方向光替代原有顶面 1.0、X 面 0.76、Z 面 0.87 的固定亮度。方向选为 `(0.2,1,-0.7)`、`(-0.2,1,0.7)`，归一化后计算；这是本项目参数，并非从游戏运行时提取的太阳位置。

当前没有 MC 的天空光/方块光传播和动态生成的光照贴图。采用有界代理：向上最多探测 8 格，树叶每层透过 0.84，遇实心遮盖乘 0.45 并终止。探测遵守隐藏树冠和燃尽移除规则。火光只查看本列与四邻列燃烧标志，暖色按逐通道最大值补充遮蔽处亮度；不累加成无限增亮。此代理以方块为单位，不逐叶片 alpha 投影，不构成真实阴影、AO 或完整 0–15 级光照传播。

三维雾距离取命中点到相机目标点的距离，避免正交射线的人工起点距离使场景整片起雾。起止距离分别为 `max(12,场景最大边×0.35)`、`max(24,场景最大边×0.8)`，雾色沿用天空 `(122,155,169)`，最大混合 0.65。因此小场景边缘和超大森林总览更明显，局部森林中心视图通常不会起雾。二维俯视保留表面光照但不加距离雾，便于查看地块与连通性。

| 已有内容 | 渲染安排 |
|---|---|
| 草、泥土、小径、石头、木板、原木、砖、灰烬 | 不透明命中 → 材质色 → 可选光照/雾 → 语义显示色 |
| 橡树树叶 | 同一 alpha 裁切 → 绿色调色 → 可选光照/雾；与燃尽状态一致 |
| 水地块 | 保留既有蓝色实体表面，可受光照/雾影响；未增加水体透明、折射或反射 |
| 燃烧、连通簇、地面选中 | 在光照之后应用既有显示色，避免光照遮盖分析信息 |
| 动画火焰 | 沿用 SDL 动画精灵叠加；无额外 GPU 阴影/泛光通道 |
| 地图纸、参照照片、字体、UI、物品图标 | SDL 原管线，场景光照不改变这些资源 |

同一开关接入单场景、二维纹理地图、基线/方案两幅独立视图及大森林诊断。它不会改变森林生成、传播概率、计费或评估数据。关闭后的 GPU 原始输出逐字节恢复原值。

## 实际性能 A/B

机器：i7-13700H、约 15.64 GiB RAM；D3D11 实际查询适配器 **NVIDIA GeForce RTX 4060 Laptop GPU**。原生像素渲染，测试未降低分辨率。1536×1536 森林，density 0.74 / seed 42，共 **109,253 个树模型实例**；大森林为渲染诊断，不扩展正式 24×20 的火势/规划规模。

每项固定同一场景/相机运动/火焰回放，按 **关闭、开启、开启、关闭** 顺序测量。每组预热 16 帧、计时 48 帧。循环 FPS 包含真实界面/呈现与原有 12ms 等待；GPU 时间戳另外测量，预热 4 次、保留 8 次，覆盖 dispatch 和 GPU 呈现纹理复制。表中 FPS 为同设置两组 FPS 的均值，GPU ms 为两组 GPU 中位数的均值。

| 场景 | 实际渲染像素 | 关闭 FPS | 开启 FPS | 关闭 GPU ms | 开启 GPU ms |
|---|---:|---:|---:|---:|---:|
| 工作台，1280×860 窗口 | 950×578 | 72.21 | 70.35 | 0.24 | 0.29 |
| 火焰回放，同上 | 950×578 | 71.23 | 68.91 | 0.35 | 0.43 |
| 工作台，2560×1380 窗口 | 2230×1098 | 69.86 | 69.49 | 0.83 | 1.08 |
| 火焰回放，同上 | 2230×1098 | 69.79 | 69.16 | 1.16 | 1.39 |
| 十万树三维总览，大窗口 | 2230×1098 | 71.69 | 71.80 | 2.83 | 3.73 |
| 十万树三维局部，大窗口 | 2230×1098 | 71.79 | 72.51 | 3.37 | 4.45 |
| 十万树二维整图，大窗口 | 1002×1002 | 72.72 | 71.97 | 1.17 | 2.56 |

开启的森林局部 GPU 时间增加约 1.08ms，总览约 0.90ms；二维代理探测占比较明显。循环内的 12ms 等待使 FPS 变化较小，不能据此判断开销为零。短测试中 GPU 时钟/调度波动明显，例如局部关闭两组分别为 4.24/2.49ms，开启为 4.42/4.48ms；略高的开启 FPS 也不代表算法加速。结果只代表这台机器和这些负载，不能换算成无帧限制最大 FPS。

## 验证与复现

```powershell
./build.ps1 -Verify
./forest-stress.ps1 -Benchmark -Shaders
```

第二条命令使用作用域内 2GB 仓颉堆并覆盖本次 shader CSV/截图，不覆盖旧 GPU/CPU 性能数据。关闭测试窗口会中止并保留已完成数据行。时间戳等待仅用于诊断，正常交互不等待查询、不读回图像。

最终 **288 项原生检查通过**，包含原 CPU/GPU 像素参照、实际 GPU 开关读回/精确恢复、不重新上传几何、燃尽状态与模型不变、本地偏好、菜单命中、CPU 禁用和比较双图同步/恢复。检查日志：[shader-checks.log](../artifacts/shader-checks.log)。截图仅核对资源与基本位置，整体明暗、雾效强度与视觉取舍由用户审查。

本版本并入之前已验收的场景内右上角 FPS 定位与橡树树苗窗口/EXE 图标。原版材质、派生图标和本地 TODO 均不上传。
