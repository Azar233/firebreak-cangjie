# 二维地图导航 v0.4.4

二维纹理地图、导入参照底图、基线/方案双栏地图，以及独立大森林俯视模式，都支持：

- 滚轮围绕鼠标位置缩放，范围为整图适配的 1–16 倍；工作台的侧栏 +/- 和 PageUp/PageDown 围绕视口中心缩放。
- 在地图内容上按住中键拖动平移。整图适配时不移动，放大后平移限制在世界边界内；边界处优先保证地图覆盖视口。
- 顶部/菜单的相机复位在二维模式恢复整图，三维模式复位原三维相机。大森林诊断的 Home 同时恢复地图和三维总览。
- 羊皮纸外框固定，内容在内部裁剪；纸边、空白区和双栏间隔不接受导航或选格。

导航不改变模型、尺度标定、预算、评估 revision、撤销记录或三维相机。二维/三维切换保留各自视图。打开新项目、新建和成功导入图片时二维回到整图；失败的打开/导入不会提前清掉现有视图。新导航状态属于会话，不写进项目或本地偏好。

选区预览尚未应用/取消时，滚轮和中键暂停导航，避免框选中途改变坐标系。按钮变换视图不会改变已存储的选区格号。菜单打开时隔离地图输入，松开中键或失去窗口焦点会结束拖动。原来的左键框选、确认应用和撤销保持不变。

## 坐标与渲染

相机保存归一化中心 `(centerU, centerV)` 和倍率 `zoom`，显示坐标到世界的映射为：

```text
worldU = centerU + (viewportU - 0.5) / zoom
worldV = centerV + (viewportV - 0.5) / zoom
```

滚轮先求鼠标下原有世界位置，再反算新中心；中键位移按视口尺寸和倍率转换。中心被限制到 `[0.5/zoom, 1 - 0.5/zoom]`，避免地图拖走或露出视口空白。

CPU/GPU 俯视射线与拾取使用同一映射。GPU 更新相机常量即可，无需重新上传森林；渲染目标始终是实际视口尺寸，不创建 16 倍宽高的巨型纹理。参照底图使用等价的放大图像矩形并裁剪，网格、保护/禁区、候选、选中格、选区和火焰位置都按同一世界矩形计算。双栏使用同一归一化相机、各自固定纸框和独立场景。

## 验证

277 项原生检查通过，原有 260 项加 17 项地图检查，包括鼠标锚点、拖动方向/释放、纸边隔离、三种图片宽高比下格中心与拾取往返、待提交选区/菜单隔离、模型与三维视图不变、按钮复位、1–16 倍限制及世界边界。

另对照 32,768 个缩放/平移后的 GPU 与 CPU 像素；验证仅改变地图相机时帧确实失效而几何仍只上传首次 4 个缓冲，渲染目标保持原生尺寸。导入真实 BMP 测试图后删除源文件，放大框选四个指定格，验证预览不修改、确认命中准确、撤销恢复且不重置倍率。双栏 GPU 实测共享导航，同时保留基线与处理的不同图像。

初轮回归发现测试用例结束后只恢复 CPU 偏好、没有恢复直接调用渲染器所用的 GPU 标志，导致后续旧 CPU 补绘断言失败。已修正测试状态清理，未放宽断言或修改基线；最终全部通过。未做新的性能矩阵或美感微调。
