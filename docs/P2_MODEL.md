# P2 连通与传播模型说明

本阶段用于观察可燃通路以及处理带对简化传播的影响。计算由仓颉实现，显示沿用原版 MC 纹理和地图纸面；不将动画作为物理模型。

## 格子和连通

- 固定 24×20 地面格，四邻接，地图横向为 x、纵向为 z。对角接触不连通。
- 原始林地相对可燃量为 1，其余为 0。方案模式中，清理植被和隔离带格均视为不可燃；原始场地模式忽略处理层。
- 禁区只约束处理操作，不阻挡火。保护标记也不自动阻燃；建筑在当前模型中不是燃料。
- 连通分量、最大分量、颜色覆盖和传播读取同一份燃料格数据，树木只是显示符号，不能按画出的树数推断燃料数量。
- 黄色通路是从起火点出发，到某个保护目标本格或四邻域的最短可燃格路径。没有路径只表示当前四邻接燃料图不通，不代表真实环境安全。

## 同步传播规则 v1

每次试验冻结燃料、保护目标、起火点、seed、传播概率 p 和燃烧持续 L 步。

1. 第 0 步将起火格置为燃烧，剩余持续步数为 L。
2. 每个仿真步，只读取上一份完整状态。每个正在燃烧的格子，对每条指向未燃可燃邻格的有向边，以概率 p 尝试点燃。
3. 新点燃的格子在本步结果中获得完整 L 步持续时间，下一步才向外传播。已有燃烧格消耗 1 步，归零后燃尽，不能再次点燃。
4. 格子不会补树或自行恢复。水域、道路、空地和处理区不会燃烧；没有飞火、跨格点燃、对角传播、风、坡度、含水率或建筑燃烧模型。
5. p 是“每条燃烧边每个仿真步”的尝试概率，同一个火源持续多步时可再次尝试。因此 p 不是静态位点占据率，也不是一场火的现实发生概率。

随机输入由规则固定的 32 位混合函数确定，以 seed、仿真步、起点格、终点格为键。分支不消耗共享随机序列，便于后续原始/方案配对比较。项目 v2 保存参数与规则版本 1，并兼容读取旧 v1 项目；未知规则版本会被拒绝。

## 保护目标指标

“目标接触”是累计有燃烧格位于保护目标本格或其四邻域的目标格数，不等于建筑烧毁数、人员损失或现实风险概率。目标接触标记随快照保存，火线离开后不撤销。当前没有保护目标损毁模型。

## 时钟、回放与失效

- 仿真步与显示帧分开。自动播放每 500 毫秒推进一个逻辑步，这是观看速度，不是现实时间标定。
- 一个界面 tick 最多补进 4 步，保留剩余时间积压；火焰贴图独立按观看时钟切帧，不改变计算。
- 暂停、失去窗口焦点后停止自动推进。上一/下一快照仅查看已经算出的状态，单步在历史末尾才生成新状态，播放也会先消费已有快照。
- 修改场地、处理、保护标记、起火点、尺度/预算或传播参数，加载项目、撤销重做以及切换原始/方案模式都会通过 revision/模式检查清除旧试验。失败的编辑或读取保留原状态。
- 重置只清除试验，保留场地、处理、起火点和参数。快照仅在本次会话内保留，项目文件保存场地和情景参数，不保存快照。

## 独立理想渗流检查

`artifacts/p2-ideal-percolation.csv` 使用独立的 32×32 四邻接位点网格，每个占据率 40 个固定 seed 样本。它只验证空图/满图端点、耦合占据下连通的单调性，以及稀疏/稠密输入的左右贯通差异。没有用这批小样本拟合临界阈值，也不把它套用到营地、传播概率 p 或现实森林。

## 显示和性能边界

连通覆盖给同一分量着色，火线为橙色与原版 MC 火焰，目标接触为红色边框。自 2026-11-02 的 P2.1 起，燃烧过程中按快照的剩余燃烧步数分阶段减少叶片；燃尽时树叶和高处原木不再绘制，只留下底部一格焦黑残桩，草地显示为中性灰烬。二维和三维共用该显示状态。它是按地面格的示意表现，不是逐个方块的燃烧或倒木物理。

每个逻辑步更新显示阶段、着色和覆盖，射线跳过烧毁部分，不重建所有树木。原始体素保持不变，回放和重置通过快照恢复完整显示；场地编辑才重建小场景。沿用预览/空闲补绘：播放期间可能看到预览，暂停后会补绘清晰帧。本阶段仍没有扩大场地或实现 Chunk/LOD，不以小场景的表现宣称大森林容量。

## MC 原版机制参考（2026-11-01）

按用户建议查看了 [MC 百科：火](https://www.mcmod.cn/item/945.html)。该页说明原版区分燃料的着火/传播属性，蔓延受雨、湿度、燃烧时长和随机更新影响。它是游戏规则参考，具体细节应区分版本。

本版借鉴有限燃烧、燃料消耗与随机蔓延，火焰使用本地原版贴图。当前规则仍为本文明确定义的同步四邻接模型；没有实现原版三维更新逻辑，也没有给单格植被强行套用方块参数。材质差异、雨湿影响和垂直传播将作为后续独立规则的参考，届时需要单独版本和验证，不悄悄改变既有情景结果。

### P2.1 燃尽表现的确定性

显示阶段只取决于快照中的剩余燃烧步数和该次试验的持续参数，不读取观看时钟、不消耗传播随机数。叶片按固定空间图案分阶段隐藏；短持续时间只有较少阶段。暂停不会继续烧掉叶片，回放同一快照得到相同可见几何。燃尽格的地面拾取仍定位原始地表，不会选中残桩或树冠。传播状态、目标接触、处理费用及原始场地文件均不因这次显示修改而改变。
